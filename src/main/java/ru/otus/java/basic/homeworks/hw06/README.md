# ООП: практика

Домашнее задание к занятию «ООП: практика».

## Цель

Попрактиковаться в задачах взаимодействия классов и объектов.

## Задание

1. Реализуйте классы Тарелка (максимальное количество еды, текущее количество еды) и Кот (имя, аппетит). Количество еды измеряется в условных единицах.
2. При создании тарелки указывается её объём, и она полностью заполняется едой.
3. В тарелке должен быть метод, позволяющий добавить еду. После добавления в тарелке не может оказаться еды больше максимума.
4. В тарелке должен быть метод уменьшения количества еды, возвращающий `boolean`. После уменьшения в тарелке не может оказаться отрицательное количество еды: если удалось уменьшить еду так, чтобы в тарелке осталось `>= 0` кусков, метод возвращает `true`, иначе — `false`.
5. Каждому коту нужно добавить поле сытость. При создании коты голодны. Если коту удалось покушать (хватило еды), сытость равна `true`.
6. Если коту мало еды в тарелке, он её не трогает: кот не может быть наполовину сыт.
7. Создайте массив котов и тарелку с едой, попросите всех котов покушать из этой тарелки и выведите в консоль информацию об их сытости.
