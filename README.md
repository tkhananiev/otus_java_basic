# Otus — Java Developer. Basic

Каждое домашнее задание — отдельный пакет `ru.otus.java.basic.homeworks.hwNN` и отдельная ветка `hwNN`, сдаётся через Pull Request в `main`.

## Структура

```
otus-java-basic/
├── pom.xml
└── src/main/java/ru/otus/java/basic/homeworks/
    ├── HomeworksApplication.java
    └── hwNN/                      — пакет с домашним заданием NN
```

## Сборка

```bash
./mvnw clean verify
```
